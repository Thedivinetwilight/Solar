## B.2 Determination: what is 20.18? (Objective B.3)

Question: is 20.18 (a) an identical calculation reused, (b) independently
measured, (c) a figure annotation derived from another dataset, or (d)
unresolved?

**V1.8 finding (honest, evidence-bound):**

1. 20.18 is **not** a table-only value: the main text states it explicitly for
   the certified tandem's subcell Jph, and the Fig. 4E legend carries it as
   the AM1.5G-equivalent current density of the plotted silicon curve. It is
   an **author-reported integrated Jph for the certified-champion / HZB EQE
   context** (exact V1.8 wording per master prompt).

2. The internal arithmetic (19.41+20.18=39.59; 20.18−19.41=0.77; and the
   separate representative-cell family 18.7+20.6=39.3) is **exactly
   consistent**, so 20.18 is a coherent, self-consistent reported number —
   against the "random typo" reading.

3. Whether 20.18 is (a) a reused calculation or (b) an independent measurement
   **cannot be determined from any publicly available copy obtained this
   session**: the main text does not say how the Jph integrals were computed
   (instrument, reference cell, mask configuration, spectrum file, window),
   and the SI (which would contain the methods + the plotted S32 data context)
   is not in hand. The fact that the champion's plotted Si branch integrates
   to ~16.90–17.11 while a sibling non-champion cell's EQE-derived Si Jph is
   20.6 leaves three live readings:
   - (c') the plotted Si branch comes from a dataset/measurement context
     different from the one behind 20.18 (same device family, different
     measurement), or
   - (b') 20.18 came from a different measurement condition (e.g., mask
     configuration) on the certified device, with the figure showing a
     different (full-stack-derived or earlier) Si response, or
   - (d) genuinely unresolved pending raw data / author clarification.

   **Classification: (d) unresolved — with (c')/(b') as the leading concrete
   candidates.** This is the most precise statement the public evidence
   currently supports. The V1.6 class SOURCE_REPORTING_INCONSISTENCY (curve
   vs reported value) stands as the supported *description*; the *cause*
   remains open.

4. **What would close it** (minimum external evidence, in order):
   1. SI methods section (EQE setup, mask, reference cell, Jph integration
      definition) — tests (c')/(b').
   2. Raw machine-readable EQE data behind Fig. S32 (author request / thesis
      data appendix) — definitive.
   3. Author clarification (corresponding author Steve Albrecht's group,
      HZB) — definitive, low cost.
