## 2. What was resolved this cycle (2026-10-01)

1. **The SI became available and was read in full.** The user committed the
   69-page accepted manuscript (`data/sources/al_ashouri_accepted_manuscript.pdf`)
   = main text + **full embedded SI** (pp26–69; Figs S1–S43, Tables S1–S3).
   Verified from it: Fig. S32 caption verbatim (p55); Table S1 (p49, incl.
   the 20.18/19.41/0.77 row and the 20.6/18.7/1.9 representative row);
   Table S2 (p50, certified J-V statistics both scan directions);
   Table S3 (p57, subcell-limited Iph set).
2. **The 20.18-vs-~16.90–17.11 mA/cm² conflict is RESOLVED (Objective A).**
   Three independent digitizations of Fig. S32 from the committed
   highest-resolution raster (native 144-dpi pixels; independent 200-dpi
   re-render; semi-manual zoom reading) give perovskite 19.321–19.565, silicon
   20.107–20.186, sum 39.428–39.751. The native-pixel method reproduces the
   printed labels 19.41/20.18/39.59 to +0.02/+0.00/+0.02 mA/cm² — inside the
   0.52-pp pixel-uncertainty band, on the bit-exact recovered spectrum, with
   **no scaling or offset anywhere** (machine-enforced). The champion's
   plotted Si branch is the branch behind 20.18 (hypotheses H3/H5/H6
   excluded; H1/H2 re-confirmed excluded; H4 excluded as an explanation).
   The conflicting 16.90–17.11 values (V1.4–V1.6) are not reproducible from
   the committed sources (their curve files are MISSING-VERIFIED) and are
   carried as immutable HANDOFF-QUOTED history, class
   SUPERSEDED-UNREPRODUCIBLE.
3. **Fig. 4E re-digitized (3 methods):** perov 19.07–19.13; Si visible
   support 18.71–19.63 (hidden leading edge ≤0.374). The 4E main-text
   schematic is a lower-fidelity rendering of the same champion data; the SI
   Fig. S32 is the audit reference. The historical 16.9019365812 "4E
   reconstruction" is not reproduced by any V1.8 method (superseded).
4. **Sahli (ref-62) cross-check closed:** drawn yellow curves integrate to
   19.604/19.453/39.058 vs the captioned measured 20.1/20.3/40.4 (−3.3%);
   ≈76 nm of the yellow perovskite curve is occluded (flagged, not assigned);
   the yellow 1-R branch shows the expected lower reflection (1.34 vs 4.23
   mA/cm² proxy, 300–1200 nm) — consistent with the caption's "reduced
   reflection" statement.
5. **Determination of 20.18 closed (Objective B):** author-reported,
   in-house (HZB) measured EQE integral of the certified champion, plotted in
   Figs. 4E/S32 and tabulated in S1 — now additionally **pixel-reproducible**
   (cycle-1 candidates (c')/(b') excluded).
