## 2. What was resolved this cycle

1. **Spectrum provenance — bit-exact recovery.** The project's reference
   spectrum is identified unambiguously: ASTM G173-03 AM1.5G global tilt, NLR
   distribution as shipped with pvlib 0.16.1 (native 0.5 nm grid,
   280–4000 nm). Evidence: integrated irradiance 1000.370656 W/m² and 100%-EQE
   incident photon current 68.982857 mA/cm² (280–5000 nm) both reproduced to
   six decimals from that table. All historical Jph numbers (V1.4–V1.6) are
   now reproducible in principle; the spectrum file itself that the prior
   session used remains MISSING-VERIFIED, but the identification evidence is
   exact, not approximate. Pinned by `tests/test_spectrum_known_answers.py`.
2. **Primary-text verification of every Fig. 4E statement** (accepted author
   version, TU Berlin DepositOnce / DNB mirror, CC BY, read in full on
   2026-09-30): 19.41 / 20.18 / 19.23 / 0.77 / 39.59 / 2.57, certification
   facts (ISE CalLab; Voc 1.90; FF 79.4%; 29.01% scan J→V; 29.15% MPP
   certified; 1.064 cm² designated area), and the caption wording
   ("certified tandem cell measured in-house", "current densities given in
   the legend").
3. **Internal arithmetic consistency proven:** 19.41+20.18=39.59 and
   20.18−19.41=0.77 exactly; separately 18.7+20.6=39.3 exactly for the
   representative cell. The reported family is coherent.
4. **New forensic constraint:** the paper contains two distinct Jph families —
   champion 19.41/20.18 (sum 39.59) and the explicitly "representative"
   (non-certified) Me-4PACz+LiF cell 18.7/20.6 (sum 39.3). The sibling
   device's Si Jph (20.6) sits with the champion's *reported* value (20.18),
   not with the champion's *plotted* Si curve (~16.9–17.1), while the
   champion's perovskite branch matches its label within ~3% (19.98 vs 19.41,
   HANDOFF-QUOTED). This asymmetry shifts the leading hypothesis to
   "plotted Si branch ≠ dataset behind 20.18" (H3/H5/H6 in the audit doc)
   and weakens the "typo" reading.
5. **Device genealogy upgraded (Objective C)** with the four linkage classes;
   champion-context pairing is represented as
   CERTIFIED_CHAMPION_CONTEXT_LINKAGE with NO_SERIAL_ID; merge guard
   machine-enforced and test-pinned.
6. **Lab-ready measurement schema delivered (Objective D):**
   `v1.8_measurement_schema.json` — 17 measurement types; every record carries
   device/measurement IDs, raw-file sha256, instrument, calibration state,
   wavelength range, spectrum, temperature, uncertainty, operator metadata,
   processing history (vertical transforms require a primary-source
   citation), provenance, timestamp, units, schema version.
7. **Strict baseline validation gate delivered (Objective E):**
   `v1.8_validation_gate.json` + `apmt/validation_gate.py` — nine checks
   (G1–G9) with explicit strict thresholds; evaluated on current evidence it
   returns FAIL/DEFER (G1: 19.23 vs 17.11 gap 2.12 > 0.30; G8: condition
   number 1.216e6 > 1e4 and boundary hits), and a synthetic fully-constrained
   evidence set passes, proving the gate is achievable, not vacuous.
8. **Reproducibility:** all V1.8 deliverables are hash-manifested
   (`manifests/v1.8_reproducibility_manifest.json`); the two authoritative
   context files are intake-logged with sha256 in `INCOMING/README.md`.

  measurements remain DATA_REQUIRED** — these are the minimum missing
  experimental evidence for the conventional baseline, unchanged from V1.7.
